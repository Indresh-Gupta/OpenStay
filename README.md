# OpenStay

A **full-featured hotel booking and review web platform** where users can explore, book, and review hotels. Authenticated users can also list their own rooms for rent, manage bookings, and interact with a trusted community through transparent reviews.

---

## Features

### 🛎 For Guests
- Browse and search hotels by location.
- View hotel details with images, prices, and amenities.
- Book hotels with instant confirmation.
- Download booking receipts in PDF format.
- Cancel bookings anytime before the stay date.
- Write and read reviews to ensure transparency.

### For Hosts
- List your own rooms or hotels for rent.
- Upload images (stored via **Cloudinary API**).
- Set prices, manage locations, and update listings.
- Edit or delete your listings anytime.

###  General Features
- Responsive design using **Bootstrap** for all devices.
- Session-based authentication and authorization.
- Secure data storage with **MongoDB**.
- Dynamic rendering with **EJS** templates.
- Review system to build trust between hosts and guests.

---
